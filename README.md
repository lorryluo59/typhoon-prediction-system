# 台风预测系统（网页仪表盘）

本地运行的全栈 Web 应用：从中央气象台台风网实时拉取真实台风路径与官方预报
（12/24/36h），当预报路径接近所选城市时，用解析式风场模型对城市各分区输出
五维影响预测：**降水量、风力等级（蒲福级）、街道积水、公共交通运行、驾车建议**。

## 功能
- 实时台风列表与完整路径（历史实况 + 官方预报轨迹 + 风圈半径）
- 10 个沿海城市（深圳、广州、上海、杭州、宁波、厦门、福州、温州、珠海、海口）
  分区级影响预测，地图按影响等级着色（综合 / 风力 / 降水可切换）
- 预警横幅：即将登陆 / 可能受影响 / 暂无影响，含预计接近时间
- 每 10 分钟自动刷新；后端 10 分钟内存缓存，数据源不可用时回退缓存并提示

## 运行
```bash
pip install -r requirements.txt
./run.sh            # 或 python3 -m uvicorn backend.main:app --port 8000
```
浏览器打开 http://127.0.0.1:8000

## 测试
```bash
python3 -m pytest tests -q
```

## 数据来源
- 台风路径：中央气象台台风网 `typhoon.nmc.cn`（免费，无需密钥）
- 分区边界：阿里 DataV GeoAtlas（构建期下载并内置到 `data/cities/`）
- 预测为启发式解析模型（Holland 风场 + 距离降水带 + 规则判定），仅供参考，
  请以官方预警为准。
